# TeeXaa® v5.0.0 — Blue Orbit Entry

نسخه بازطراحی‌شده TeeXaa با تمرکز کامل روی هویت بصری اختصاصی.

## تغییرات این نسخه
- Splash حدود ۱۵ ثانیه با انیمیشن چندمرحله‌ای واقعی حلقه‌ها.
- تشکیل تدریجی سه مدار، چرخش، ذرات، نور و سپس شکل‌گیری لوگوتایپ TeeXaa.
- پالت بصری فقط در خانواده آبی؛ صورتی و بنفش حذف شده‌اند.
- لوگوی ورود با لوگوی آیکون برنامه کاملاً جداست.
- آیکون برنامه، 512×512 و 192×192 بر اساس نماد حلقه‌ای جدید ساخته شده‌اند.
- آیکون 1024×1024 نیز اضافه شده است.
- فونت فارسی Estedad و فونت لاتین Space Grotesk استفاده می‌شود.
- تمام فایل‌های پروژه در ریشه هستند و پوشه assets/icons وجود ندارد.

## نکته اتصال داده
صفحه بازار از APIهای عمومی موجود در کد برای دریافت نرخ‌های مرجع استفاده می‌کند. نرخ بازار آزاد ایران یا معاملات واقعی به بک‌اند و منبع داده مناسب نیاز دارد.
